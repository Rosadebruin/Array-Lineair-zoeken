# Array-Lineair-zoeken
Files for Array Lineair zoeken 

How do you open the lineair and bineair files?
1. Open the folder with the files.
2. In the file path search "cmd".
3. a cmd.e opens, fill in "php -S localhost:8000 filename".
4. It gives the link of the localhost, copy that and search it in your browser.
5. Now you can see the .php file.
